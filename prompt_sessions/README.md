## 내보내는 방법

Claude Code 대화 기록을 `.md`로 저장합니다.
- 앱에서 세션 내용을 복사해 붙여넣거나,
- 로컬 기록(`~/.claude/projects/<프로젝트>/`)의 대화 로그를 정리해 사용합니다.

## ⚠️ 제출 전 필수 확인

로그에 비밀값이 섞이지 않았는지 반드시 검색하세요.

```bash
grep -rniE "sk-[A-Za-z0-9_-]{20,}|serviceKey=|authKey=|OPENAI_API_KEY *=|KMA_SERVICE_KEY *=" prompt_sessions/
```
