## 이 기록에서 확인 가능한 것

- **AI에 시킨 것과 시키지 않은 것의 경계** — 결론·수치는 사람이 원자료로 재검증, AI에는 설계·구현·자가 감사를 맡김
- **AI 주장을 기각한 장면** — 원자료 대조로 근거가 없다고 판단해 반영하지 않은 사례 11건
- **자가 레드팀의 실제 작동** — AI에게 자기 결과물을 공격하게 하고, 적발 44건을 전량 수정
- **실패 원인 규명 과정** — AI 감사관 간헐 502의 원인을 추정이 아니라 계측으로 특정

요약·방법론 정리본은 상위 폴더 [`AI_활용_기록.md`](../AI_활용_기록.md) 참조.

## 재생성 방법

```bash
python scripts/export_sessions.py
```

`~/.claude/projects/` 아래 원본 `.jsonl`을 읽어 이 디렉터리에 다시 씁니다.

내보내기 시점에 API 키 패턴을 `<REDACTED>`로 치환합니다. 제출 직전 재확인:

grep -rniE "sk-[A-Za-z0-9_-]{20,}|serviceKey=|authKey=|OPENAI_API_KEY *=" prompt_sessions/
