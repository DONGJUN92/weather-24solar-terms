## 근본 원인
차트를 SVG 문자열로 그릴 때 색상을 **프레젠테이션 속성에 CSS 변수**로 넣었습니다 — 예: `stroke="var(--blue)"`, `fill="var(--summer)"`.
`var()`는 **CSS 문맥(스타일시트·인라인 style)에서만 동작**하고 **SVG 속성값에서는 비표준**입니다. Chromium은 우연히 해석해 주지만, **Safari·Firefox·`file://` 웹뷰(미리보기 패널 포함)에서는 해석되지 않아**:
- 곡선의 `stroke`가 사라져 **선이 안 보이고**
- 기준선·월 눈금이 사라지고
- 절기 점·라벨이 **검정으로** 깨짐 → "오류가 많은" 상태로 보입니다.

제가 처음에 Chrome으로만 확인해 놓쳤던 부분입니다. (참고: 앞서 보인 "강릉/+0.3℃" 이상값은 제가 디버깅하며 누른 클릭이 누적된 것으로, 새로고침하면 정상 기본값이라 앱 버그는 아니었습니다.)

## 해결
SVG에서 `var()`를 **전부 제거**하고, 렌더 시점에 `getComputedStyle`로 CSS 변수를 **실제 hex로 해석**해 주입하도록 변경했습니다(라이트/다크 자동 동기화). 다크모드 전환 시 재렌더 리스너도 추가했습니다.
