# Weather24 — 절기의 약속 검증소

> **2026 기상·기후 AI 해커톤 경진대회** 출품작
> 24절기라는 조상의 '계절 약속'이 내 지역에서 아직 유효한지, 기상청 실측 자료로 학습자가 직접 검증하는 체험형 기후 교육 웹앱

## 1. 무엇을 배우는가

중학교 3학년 ~ 고등학교 2학년 학습자가 다음 다섯 가지를 **수행으로** 익힙니다.

| 학습목표 | 학습자가 할 수 있게 되는 것 |
|---|---|
| ① 절기 ≠ 기후 | 24절기가 태양 위치로 정한 천문 날짜임을 설명하고, 그 무렵 관측된 기온 변화와 구분할 수 있다 |
| ② 자료의 범위 | 한 지점·5년 자료로 말할 수 있는 것과 없는 것을 구분해 결론의 범위를 좁힐 수 있다 |
| ③ 기준을 정의 | ‘덥다’·‘여름’·‘비가 많다’ 같은 모호한 말을 임계값으로 정의하고, 기준을 바꾸면 결론이 달라짐을 설명할 수 있다 |
| ④ 근거만큼 결론 | 주장·근거·추론·**한계**(CERL)를 갖춘 한 문장을 스스로 작성할 수 있다 |
| ⑤ 관측과 모형 | 물리 법칙 하나로 계절을 **직접 계산해** 보고, 모형이 맞히는 것과 맞히지 못하는 것의 경계를 말할 수 있다 |

### 핵심 체험 — 기준선 하나

학습자는 관측 자료가 없는 별도 화면에서 먼저 예측을 봉인합니다. 그 다음 화면의 보라색
**‘덥다’ 기준선**을 직접 정합니다(드래그 · 슬라이더 · ± 스테퍼 · 의미 있는 프리셋).
정하는 즉시 차트 바로 위의 숫자가 바뀌며, 전문가 예시를 보기 전에 자기 CERL 네 요소를 작성합니다.

```
무자료 예측 → 질문 확인 → 한 가지 조작 → 증거 정리 → CERL 4요소 순차 작성
→ 자가진단 → 전문가 예시 비교 → 범위 감사
```

각 화면은 **한 가지 인지 과업과 한 가지 주행동**만 우선 제시합니다. 기존의 관측값·출처·
심화 해석·전문가 예시·공유 기능은 삭제하지 않고 다음 사고 단계 또는 접힌 선택 심화로
재배치했습니다. 세부 화면 구성과 데이터 보존 대조표는
[`학습단계_분할_기획서.md`](학습단계_분할_기획서.md)에 정리되어 있습니다.

### 학습 동선 (설계 시간 69~76분 · 2차시)

미션 하나는 **핵심 + 선택 심화**로 나뉩니다. 아래 표의 값을 모두 더한 **설계 시간이 69~76분**(2차시)입니다.

> ⚠️ **실제 소요 시간은 아직 측정하지 않았습니다.** 아래 '핵심' 열은 설계 목표이지 관측된 완료 시간이 아닙니다.
> 미션 하나가 8~10개 마이크로 화면이고 필수 서술이 2~4칸이므로, 실제로는 더 걸릴 가능성이 큽니다.
> [`학생_파일럿_검증계획.md`](학생_파일럿_검증계획.md)의 무설명 테스트로 중앙값·90백분위를 재고 나서 이 자리에 그 숫자를 적습니다.

| 단계 | 내용 | 핵심 | 심화 포함 |
|---|---|---|---|
| 🌍 24절기 입문 *(선택)* | 지구 공전 궤도 위 24절기 · 한자 풀이 · 왜 조상들이 만들었나 · “여름은 태양에 가까워서 덥다” 오개념 교정 | — | 5분 |

#### 조작 변수 4축 (Mo1 p.29 “변수 2~3개”)

| 축 | 조작 | 무엇이 반응하는가 | 어디서 |
|---|---|---|---|
| **세로 — 기준값** | ‘덥다’를 몇 도로 정할지 슬라이더·드래그 | 관측 집계가 다시 계산됨 | 미션 1~4 · 자유탐구 |
| **가로 — 날짜** | 가장 더울 것 같은 날을 직접 찍기 | 실제 극값일과의 차이 | 미션 5 |
| **기간 — 비교 창** | ‘현재’로 쓸 5년을 26가지 중에서 선택 | 결론이 흔들리는지 여부 | 자유탐구 |
| **물리 — 열용량·온실효과** | 열을 머금는 층의 두께(0.5~60m), 대기가 가두는 열(0~12 W/m²) | **에너지 균형 방정식이 1년치 기온을 다시 적분** | 🔬 열관성 실험실 |

여기에 **지역**(16지점 지도 클릭)과 **지표**(기온·습도·강수) 선택이 더해집니다.

> **“이건 시뮬레이터가 아니라 데이터 뷰어 아닌가?”**
> 앞의 세 축은 *관측 자료*를 조작합니다(요강 FAQ Q4의 “실제 기상 데이터를 직접 조작”).
> 네 번째 축은 *모형*을 조작합니다 — `C·dT/dt = Q(날짜,위도) − (A + B·T)`를 365일 적분해
> 학습자가 바꾼 물리량에 기온 곡선이 반응합니다. 사전계산된 값을 꺼내 오는 것이 아닙니다.
> **두 가지가 다 필요합니다**: 자료가 무엇을 말하는지, 그리고 왜 그런지.

교사용 인쇄물: [`prototype/교사_학습지.html`](prototype/교사_학습지.html) — 수업 흐름 · 활동지 · 오개념표 · 평가 루브릭(6점) · 2022 개정 성취기준 연결

## 2. 구동 환경 · 배포 방법

### 필요 환경
- **사용자**: 최신 크롬(또는 Edge·Safari). 별도 설치 없음
- **개발/재빌드**: Python 3.10+ (`pandas`, `numpy`, `requests`), Node.js 18+ (검증 스크립트용)
- **배포**: Vercel (정적 파일 + 서버리스 함수 1개)

### 로컬에서 실행
```bash
# 저장소 루트에서 정적 서버를 띄운다 (web_data/ 접근이 필요하므로 루트에서)
python -m http.server 8777
# 브라우저에서 http://localhost:8777/prototype/index.html
```
> 로컬에서는 `/api/ai-turn`이 없으므로 AI 감사관은 **규칙 기반 점검으로 자동 대체**됩니다. 학습 동선은 100% 동작합니다.

### 배포 (Vercel)
```bash
vercel --prod
```
- 라우팅은 [`vercel.json`](vercel.json)이 처리합니다(`/` → `prototype/index.html`, `/web_data/*`, `/api/*`).
- **환경변수**(Vercel → Settings → Environment Variables):

| 변수 | 필수 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | 선택 | AI 증거 감사관용. **없어도 앱은 정상 동작**하며 규칙 기반 점검으로 대체됩니다 |
| `OPENAI_MODEL` | 선택 | 기본값 `gpt-5.4-mini` |

> ⚠️ 키는 **환경변수에만** 둡니다. 저장소·클라이언트 번들·배포 산출물 어디에도 키가 없습니다(§5 참조).

### 데이터 재빌드
```bash
# 1) 원시 수집 (기상청 API 키 필요 — 아래 참조)
set KMA_SERVICE_KEY=발급받은_키          # Windows
export KMA_SERVICE_KEY=발급받은_키       # bash
cd data_collectors && python collect_kma_allyears.py

# 2) 가공 + 회귀 검증 (실패 시 exit 1)
cd ../processing
python build_solar_terms.py      # → prototype/solar_terms_data.js, web_data/solar_terms_climatology.json
python verify_solar_terms.py     # 총 8,359건 = 데이터 8,213 + 인터페이스·문서 146 (원시 CSV 없으면 --no-raw)
```

`KMA_SERVICE_KEY`는 [공공데이터포털](https://www.data.go.kr) 또는 [기상청 API 허브](https://apihub.kma.go.kr)에서
**본인 계정으로 발급**받아 환경변수로 지정합니다. 발급 절차: [`data_collectors/API_KEY_발급_가이드.md`](data_collectors/API_KEY_발급_가이드.md)

## 4. 생성형 AI 활용

### 결과물 제작 과정에서의 활용
개발 전 과정을 **Claude Code**로 진행했습니다. 프롬프트 세션 기록과 방법론은

요약: 51개 커밋 · 데이터 파이프라인 설계 → 앱 구현 → **AI 레드팀 자체 감사(5라운드)** → 전량 수정 → 프로덕션 검증.
특히 레드팀 단계에서 **AI가 자기 결과물의 과학적 오류를 잡아내고 수치로 반증**한 과정이 이 프로젝트의 AI 활용 핵심입니다.

### 결과물 안에서의 AI
`/api/ai-turn` — **증거 감사관**. 학습자가 쓴 판정문에서 과장·범위 이탈·인과 단정을 짚습니다.

- 결론을 **대신 쓰지 않습니다.** 모든 미션에서 학생이 주장·근거·추론·한계를 먼저 작성해야 자가진단과 전문가 예시가 열립니다.
- 화면에 표시된 증거 카드 범위 안에서만 답하도록 시스템 지침과 JSON 스키마(strict)로 강제합니다.
- 기본 버튼은 외부 전송이 없는 **기기 안 빠른 점검**입니다. 외부 AI 감사는 전송 문구를 읽고 체크박스에 동의한 경우에만 활성화됩니다.
- **AI가 실패해도 학습이 끊기지 않습니다** — 규칙 기반 점검(정규식 6종)이 같은 항목을 즉시 확인합니다.
- **정량 검증한 것은 “AI가 죽어도 반드시 동작하는 쪽”입니다** — 규칙 기반 점검(`localAudit`)을 한국어 학습자 답안 100케이스로 평가해 **100/100**,
  잘 쓴 답을 잘못 지적한 **오탐 0건**(good_scoped 13/13 · hold_valid 12/12 · injection 12/12).
  AI 경로가 아니라 폴백 경로의 점수라는 점을 분명히 밝힙니다. 재현: `node eval_harness.js` · 데이터 `eval_set.json`

## 7. 과학적 무결성 — 이 앱이 스스로 지키는 약속

교육용이라도 수치를 부풀리지 않기 위해 다음을 코드와 검증 게이트로 강제합니다.

1. **일수는 곡선이 아니라 실측에서 센다.** 화면의 ‘더위일’은 연도별 실제 관측값으로 세어 평균한 값입니다.
   보기용 평활 곡선에서 세면 고임계에서 과소·저임계에서 과대해지므로 쓰지 않습니다.
2. **불완결 연도를 섞지 않는다.** 관측 350일 미만 연도는 평년 비교에서 제외하고(2026년 등),
   지점별로 실제 사용한 연도 수를 화면에 표기합니다.
3. **자기 자료의 흔들림을 공개한다.** “5년 창을 옮기면 시차가 +4~+17일에서 움직이고, 30년으로 보면 +10일”을
   판정문의 한계 절과 방법론 서랍에 함께 적습니다.
4. **상관을 인과로 말하지 않는다.** CO₂–기온 그래프에 r²를 보여주되, 원인을 말하려면 다른 종류의 증거가
   필요하다는 사실을 같은 화면에서 밝힙니다.
5. **계산할 수 없는 것과 계산하지 않은 것을 구분해 말한다.** 화면의 곡선·기준선·일수는 모두 **일 평균값**입니다.
   ASOS 원자료에는 최고·최저기온이 있으므로, 8지점에 한해 **폭염일(일 최고 33℃↑)·열대야(일 최저 25℃↑)·결빙일**을
   실제로 세어 ‘기상청 기준표’ 서랍에 실었습니다(서울 폭염일 4.2 → 22.5일, 열대야 3.2 → 31.5일).
   다만 그 지수는 **비교 기간이 다르므로**(과거 1969–73 5년 vs 현재 2022–25 4년) 미션의 수치와 나란히 놓을 수 없다고 화면이 밝힙니다.
   특보 발표 기준(“2일 이상 지속”)은 재현하지 않고 그렇게 표기합니다.
6. **모형과 관측을 섞지 않는다.** 열관성 실험실의 파란 곡선은 **계산 결과**이며, 화면 맨 위와 방법 서랍에서
   “이것만은 관측 자료가 아니다”라고 먼저 밝히고 단순화 5가지를 나열합니다.
7. **자기 결론의 흔들림을 스스로 잰다.** 계절 지연을 5년 중 한 해씩 빼며 다시 계산해(잭나이프) 그 흔들림을 데이터에 기록하고,
   화면이 “한 해만 빼도 최대 N일 흔들린다”를 함께 말합니다. 지점 간 차이가 흔들림보다 크지 않으면 **인과를 단정하지 않습니다.**
8. **모든 화면에 출처·표본 수·계산 방법·한계**를 ‘이 숫자는 어떻게 나왔나’ 서랍으로 제공합니다.
9. **학습 순서를 기능보다 먼저 지킨다.** 자료가 없는 화면에서 예측하고, 학생이 CERL 네 요소를 먼저 쓴 뒤에만
   자가진단·전문가 예시·다음 미션이 열립니다. 외부 AI 점검은 전송 범위 고지와 명시적 동의 뒤에만 활성화합니다.

검증: `python processing/verify_solar_terms.py`
(구조·표본·단조성·실측대조·부호방향·rainFlip·계절지연·극값안정·이동창·**문서대조·절기날짜·전지구완결성·지연안정성·극한지수·학습계약**, 총 15축 —
**총 8,359건 = 데이터 8,213건 + 인터페이스·문서 146건**)
원시 ASOS CSV가 없는 zip 제출본에서는 `python processing/verify_solar_terms.py --no-raw`로 구조·문서·전지구·안정성 축만 실행합니다.
